# 周超 / CHAL ZHOU — 个人作品集

本地运行：`npm run dev`。根路径 `/` 与 `/portfolio` 都直接进入完整内容页，没有单独的起始页。

## 内容结构

1. **首屏与个人介绍**：直接进入“让视觉成为解决问题的力量”内容页，接续个人肖像预留位、9 年经验介绍与工作经历。
2. **作品图集**：品牌视觉系统、线下物料、C4D 产品建模、AIGC、电商页面、手绘与视觉探索，按参考图分区呈现。
3. **工作方法与工具**：说明问题梳理、视觉落地、AI 协作和人工精修的工作路径。
4. **联系收尾**：提供可复制的合作邀约文案。源文档未包含个人邮箱或电话，后续可补入真实联系方式。

## 设计规范

- **视觉方向**：暗炭黑底色、低饱和灰白文字、酸橄榄绿强调色；使用细线、克制的网格与少量光效表达科技感。
- **字体**：全站使用阿里巴巴普惠体 3.0；标题、卡片标题、正文和辅助信息按 75 / 55 / 30 / 15px 组织，最小字号 15px。字重按重要程度使用 Bold、SemiBold、Medium、Regular 与 Light。
- **桌面布局**：作品主画布最大宽度 1500px；大图按通栏主视觉展示，小图同排等高、按图片比例决定宽度；个人介绍采用图文分栏。
- **平板与移动布局**：内容区按屏幕收窄；作品横排保持图像比例，可横向滑动；手机导航折叠，标题与段落按可读宽度换行。
- **交互**：导航滚动后收成圆角磨砂悬浮栏；页面锚点、移动菜单、复制合作邀约；支持减少动态效果偏好。

## 素材

品牌视觉区已接入 `public/images/ansmen-vi/` 内的 36 张图片；01.jpg 同时用于主视觉和网格首格，网格依 01—36 顺序排列。其余作品图片保留无文案占位块。`ImageSlot` 支持传入 `src`，加载后会读取原图宽高比，让同排图片保持同高度且不变形；大图区域最大宽度为 1500px。后续素材可放入 `public/images/` 后直接替换对应图块。
